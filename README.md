 المراية الذكية 

نظام مراية ذكية يحلل إطلالة المستخدم محلياً ويقدّم نصائح تنسيق ألوان نصاً على الشاشة وصوتاً بالعربية، مع دعم توليد الردود بالذكاء الاصطناعي ونظام شخصيات قابل للتخصيص لكل عميل، دون الحاجة لإنترنت أو أي خدمات سحابية مدفوعة.



عند وقوف المستخدم أمام المراية لثلاث ثوانٍ، تلتقط الكاميرا صورة تلقائياً، فيفصل النظام جسم المستخدم عن الخلفية بكسل بكسل، ويستخرج ألوان القطعة الفوقانية والتحتانية والحذاء، ثم يولّد نصيحة تنسيق مبنية على قواعد ألوان حقيقية، تظهر على الشاشة وتُنطق صوتياً. كل المعالجة تتم على الجهاز نفسه، فلا تغادر أي صورة الجهاز ولا توجد أي تكاليف تشغيل شهرية.

## التقنيات المستخدمة

| المكوّن | التقنية | الدور |
| --- | --- | --- |
| التشغيل | Raspberry Pi 5 (أو أي جهاز) | الجهاز الأساسي |
| البرمجة | Python | لغة المشروع |
| الرؤية | OpenCV | التعامل مع الكاميرا والصور |
| كشف الشخص | YOLOv8n-seg (Ultralytics) | فصل الجسم عن الخلفية بكسل بكسل |
| استخراج اللون | KMeans + HSV | إيجاد اللون المسيطر وتسميته بالعربية |
| النصائح | قواعد تنسيق مكتوبة بالكود | تناسق الألوان والألوان الحيادية |
| الصوت | Piper TTS | نطق النصيحة بصوت عربي محلي |
| الواجهة | Flask + HTML | شاشة المراية (ساعة + نصيحة) |

## آلية العمل

1. الكاميرا تعمل باستمرار وتراقب المشهد
2. عند ثبات شخص أمام المراية ثلاث ثوانٍ تُلتقط صورة
3. يفصل YOLO جسم المستخدم عن الخلفية ويستبعد الخلفية نهائياً
4. يُقسَّم الجسم لثلاث مناطق: فوقانية وتحتانية وحذاء
5. تُستخرج الألوان المسيطرة من كل منطقة بعد فلترة بكسلات البشرة
6. تُولَّد نصيحة من قواعد التنسيق (تناسق، ألوان حيادية، اقتراح بدائل)
7. تظهر النصيحة على الشاشة وتُنطق عبر Piper
8. تعود المراية لحالتها الطبيعية، مع فترة انتظار 30 ثانية بين نصيحة وأخرى

## بنية المشروع

```text
smart-mirror/
├── main.py               السكربت الرئيسي: المراقبة والتنسيق بين المكونات
├── detector.py           كشف الشخص وفصله عن الخلفية وتحليل المناطق
├── colors.py            استخراج اللون المسيطر وتسميته (KMeans + HSV)
├── rules.py             قواعد التنسيق وإرجاع نتيجة خام
├── persona.py           تحميل الشخصية وتوليد النص النهائي مع تنويع الردود
├── llm.py               توليد الردود عبر نموذج لغوي محلي (Ollama)
├── db.py                تسجيل الإحصائيات (SQLite)
├── tts.py              النطق الصوتي (Piper على لينكس / pyttsx3 على ويندوز)
├── app.py               خادم الويب ولوحة التحكم
├── config.py            إعدادات النظام العامة
├── persona.json         الشخصية النشطة حالياً
├── personas/            شخصيات جاهزة (cafe, restaurant)
├── templates/           index.html واجهة المراية + admin.html لوحة التحكم
├── requirements.txt     المكتبات المطلوبة
├── setup_windows.bat    تجهيز تلقائي على Windows
├── run_windows.bat      تشغيل بضغطة واحدة على Windows
└── setup.sh             تجهيز تلقائي على Raspberry Pi
```

 التشغيل على Windows 

```powershell
setup_windows.bat
run_windows.bat
```
`http://localhost:5000`

 التشغيل على Raspberry Pi

```bash
bash setup.sh          # مرة واحدة فقط: يثبّت كل شيء تلقائياً
source ~/mirror-env/bin/activate
python main.py
```

## ملاحظات

- أول تشغيل ينزّل نماذج YOLO تلقائياً (يتطلب إنترنت مرة واحدة فقط)
- للحصول على أفضل نتيجة يجب أن يظهر الجسم كاملاً أمام الكاميرا
- قواعد التنسيق قابلة للتعديل بسهولة من ملف `rules.py`
- النطق الصوتي يعمل حالياً على Linux (Raspberry Pi) عبر Piper
